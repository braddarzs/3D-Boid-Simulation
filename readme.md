# Worksheet 4

## Implementation and Controls

The final artifact is a boid simulation in an underwater environment, with the included user interaction:

### Camera

The camera can be moved with WASD, as well as SHIFT and CONTROL for up and down movement respectively. TAB can be used to lock and unlock the camera.

### Magnet

The magnet can be moved when the camera is locked. It can be moved with the same controls as the camera.

### Predator and Prey Spawning

Predators and prey can be spawned with S and F respectively, they will spawn in set bounds in the scene.

### Food Spawning

Food can be spawned when the camera is locked. Clicking anywhere in the scene will spawn food, at the point a raycast hits, fired from the camera to the position clicked.
